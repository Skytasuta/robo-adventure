Robo Adventure 3D (fixed launch)
Windows: Double click START_3D_WINDOWS.bat (requires Python installed).
Or terminal: cd robo_adventure_3d && python -m http.server 8765
Then open http://localhost:8765 in Chrome.
Internet is needed for Three.js CDN; if unavailable the playable 2D fallback will display after 3 seconds.
Opening index.html directly may block the 3D ES module.
Google Sheets not yet connected.
